Build **Z Note**, a minimal Markdown note-taking web app using Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, and Vercel Postgres (Neon).

**Features:**
- Create, edit, delete, and search notes
- Markdown editor with live preview and split view
- Automatic saving with save status indicator
- Pin important notes and sort by recently updated
- Responsive layout with light/dark themes
- Simple sidebar with notes list and search

**Design:** Clean, minimalist, premium UI with a **strict graphite gray and white color palette**. Use the hand-drawn graphite `Z` logo as the brand identity. No yellow, accent colors, unnecessary shadows, or decorative elements.

**Deployment:** Must support one-click Vercel deployment with automatic database provisioning, environment configuration, and schema initialization. No authentication for v1.

Keep the app lightweight, simple, and production-ready. Include a README and `.env.example`.
